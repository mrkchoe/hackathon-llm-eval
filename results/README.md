# Published results

Committed measured summaries for suite **T1–T10** (30 trials/model). No API keys, no `.env`.

Each `*_summary.json` includes:

- pass/fail rates (unchanged from the live runs)
- verified token totals
- suite wall-clock timing from saved traces
- cost estimate when rates are known; otherwise `unknown` / free-tier `$0`

See [`RESULTS.md`](RESULTS.md) for the human-readable table. Raw local traces stay in `../outputs/` (gitignored).
